# 에이두 한글 개인정보 처리방침

에이두 한글은 교사가 운영하는 학습 서비스입니다. 이 방침은 계정과 학습 자료의 저장 위치, Google 로그인과 AI 기능의 처리 범위, 삭제·탈퇴 요청 방법을 안내합니다.

## 1. 처리 목적과 항목

계정 생성·로그인과 이용자 구분, 교사·학생 연결, 학습 진행 저장·조회와 기기간 이어하기, 학습 자료 생성·보관, 문의 및 권리행사 처리, 계정 보호와 장애 대응을 위해 필요한 정보를 처리합니다.

학생 계정은 별명, 로그인 번호, 계정 식별자(UID), 연결 교사, 학습 설정·진행·결과·기록을 사용합니다. 교사 계정은 로그인 이메일, 인증 식별자와 표시 이름 등 계정 정보 및 연결 학생의 학습 관리 정보를 사용합니다. 이용자가 입력·업로드하거나 저장한 글·사진·파일, AI 요청과 결과, 문의 내용도 해당 기능의 제공·보관에 필요한 범위에서 처리합니다. 인증·보안을 위해 IP 주소, 기기·브라우저 정보, 접속·오류 기록과 로그인 유지 정보가 처리될 수 있습니다.

학생은 실명 대신 별명과 로그인 번호를 사용하는 것이 기본입니다. 학생에게 자동 부여되는 인증용 이메일 형식은 실제 연락 이메일이 아닙니다. 별명이라도 다른 기록과 연결되어 개인을 알아볼 수 있으면 개인정보로 취급합니다. 비밀번호, 주민등록번호, 연락처, 주소, 건강·장애 등 민감정보와 다른 사람의 개인정보를 학습 입력창·사진·파일에 넣지 마세요.

## 2. 교사 개인 서버에 보관하는 데이터

에이두의 계정 프로필, Google 로그인 계정과 연결된 서비스 계정 정보, 교사·학생 연결, 학습 진행·결과·기록, 저장한 자료와 AI 생성 결과는 교사가 직접 관리하는 에이두 자체 서버의 SQLite 데이터베이스 및 파일 저장소에 보관합니다. 학습 데이터의 저장소로 Google Firestore나 Firebase Storage를 사용하지 않습니다.

Google 로그인은 신원을 확인하는 인증 수단입니다. 인증 결과의 계정 식별자 등을 자체 SQLite 계정 정보와 대조·연결하여 에이두 계정을 구분하고 접근 권한을 확인합니다. 이는 Google 계정 전체나 Google에 보관된 개인 자료를 복사·수집한다는 뜻이 아닙니다.

다만 ‘Google 로그인을 포함한 모든 정보가 자체 서버에만 존재한다’는 뜻은 아닙니다. Firebase Authentication에는 로그인에 필요한 별도의 인증 계정과 인증·보안 정보가 존재하며, 기기에도 로그인 유지·임시 저장 정보가 남을 수 있습니다. 인증 계정과 에이두의 학습 데이터 저장소는 구분됩니다.

## 3. Google 로그인과 Firebase Authentication

Firebase Authentication은 운영자가 관리하는 개인 Firebase 프로젝트에서 로그인·계정 인증 목적으로 사용합니다. Google 로그인에 필요한 계정 식별자, 이메일·표시 이름 등 로그인 방식에 따른 정보와 인증용 토큰, 접속·보안 정보는 Google/Firebase의 인증 절차에서 처리될 수 있습니다.

Google 로그인만으로 Google이나 무관한 제3자에게 에이두 자체 서버의 학습 기록·사이트 이용 기록을 열람하거나 가져갈 권한이 생기지는 않습니다. 에이두는 Google 로그인을 이유로 학습 기록이나 사이트 이용 데이터를 Google에 제공하지 않으며, 이용자의 개인정보를 판매하거나 무관한 제3자에게 임의 제공하지 않습니다. 인증에 필요한 Google/Firebase의 처리는 이 설명과 별개입니다.

Firebase 인증 정보는 Google의 국외 인프라에서 처리될 수 있습니다. 적용되는 처리 조건과 보관·삭제 절차는 Firebase의 공식 개인정보 안내도 함께 적용됩니다. 국외 이전 등 별도 고지·동의가 필요한 처리는 해당 법적 절차를 따릅니다.

## 4. AntiAI의 AI 라우팅과 개인정보·위험정보 필터링

에이두 한글의 AI 요청과 응답은 자체 AntiAI 서버의 API를 통해 처리합니다. 이용자의 브라우저에서 Gemini API를 직접 호출하는 방식과는 구분되지만, AntiAI가 모든 추론을 로컬에서만 수행한다는 뜻은 아닙니다. AI 기능에 필요한 문장·사진·학습 자료 등 입력과 생성 결과가 이 처리 경로에서 사용됩니다.

AntiAI는 로컬 AI와 외부 AI를 연결하는 라우터입니다. 로컬 이미지 생성·편집 후보는 동일 네트워크의 BC-250에서 Vulkan으로 실행하는 Qwen-Image 2.1이며, 로컬 문장 처리 후보는 개인 데스크톱의 RX 6600 8GB에서 처리하도록 구성한 Gemma4 12B Q4입니다. 모델 설치 여부와 별개로 연결·준비·작업 검증 상태를 확인하며, 해당 조건을 충족하지 못하면 로컬에서 처리했다고 표시하지 않습니다.

현재는 속도와 동시 이용 시의 대기를 줄이기 위해 로컬 문장 처리에 최대 1초, 이미지 경로 확인·처리에 최대 1.5초의 짧은 대기 예산을 적용합니다. 로컬의 연결 실패·준비 미완료·혼잡·시간 초과 시 Antigravity CLI 경로로 빠르게 전환합니다. 연속 실패 시에는 잠시 로컬 재시도를 줄입니다. 이 때문에 실제로는 다수 요청이 기존 Antigravity CLI의 Gemini Flash 계열 모델에서 처리될 수 있습니다. 모델 버전은 운영 설정에 따라 달라지며 특정 버전에 영구 고정된다는 의미가 아닙니다. 이미지 경로에는 기존에 설정된 외부 예비 제공자(OpenAI/Codex)가 가용성·할당량 장애 시 사용될 수도 있습니다.

로컬 AntiAI 서버는 로컬·외부 경로를 선택하기 전에 입력 문장을 점검합니다. 현재 적용한 규칙은 주민등록번호 형식, 휴대전화번호, 이메일, ‘이름:’ 등으로 명시한 이름의 마스킹과 일부 명확한 위험 요청의 차단입니다. 생성된 문장·구조화 응답에도 같은 유형의 점검을 적용합니다. 이는 규칙 기반의 제한된 점검이며 모든 이름·주소·민감정보나 위험 내용을 탐지하는 기능은 아닙니다. 차단된 내용을 다른 모델로 보내 우회하지 않습니다.

사진·첨부파일의 얼굴, 손글씨 속 개인정보, 문서 내용과 이미지의 유해 장면까지 자동으로 모두 판별·제거한다고 보장하지 않습니다. 파일 형식·크기·접근 권한 검증과 이미지 내용의 개인정보 제거는 서로 다릅니다. 마스킹되지 않은 사진·문서 정보가 요청한 외부 AI 경로로 전달될 수 있으므로, 업로드 전에 불필요한 개인정보를 직접 지우거나 가려 주세요. 비밀번호·인증 토큰·주민등록번호·건강·장애 등 민감정보는 AI 입력에 넣지 마세요.

자체 서버를 경유하거나 브라우저에서 Gemini API를 직접 호출하지 않는다는 이유만으로 Antigravity·Google/Gemini 또는 설정된 예비 제공자의 약관·개인정보 처리 조건이 적용되지 않는 것은 아닙니다. 외부 전송 시에는 선택한 자료와 필터링 후의 문장, 기능 수행에 필요한 요청 정보가 해당 제공자에게 전달될 수 있습니다. 보관·모델 개선 사용 여부를 일괄적으로 ‘없음’이라고 보장하지 않으며 실제 계약·약관·데이터 처리 조건이 적용됩니다. 외부 전송 대상·항목·국가·보관기간 등 필요한 안내와 동의 절차는 실제 경로에 맞게 적용합니다.

완전한 로컬 처리를 확대하기 위해 RAM 128GB·VRAM 32GB 서버 환경을 주문·구성 중입니다. 아직 완성·검증된 운영 환경은 아니며, 완료 전까지 위의 로컬 후보·Antigravity 중심 혼합 라우팅을 사용합니다. 새 서버를 도입하거나 외부 전송 범위를 변경하면 실제 운영 상태에 맞춰 다시 안내합니다.



## 5. 보유기간과 삭제·탈퇴

계정·학습 기록은 서비스 이용과 저장 목적이 유지되는 동안 보유합니다. 입력·업로드 자료와 생성 결과는 이용자가 저장한 목적에 필요한 기간 동안 보관합니다. 문의·권리행사·동의 확인 자료와 보안·오류 기록은 해당 처리에 필요한 기간에 한해 보관하고, 불필요해지면 파기합니다.

이용자 또는 적법한 법정대리인은 언제든 개인정보와 학습 데이터의 삭제 또는 계정 탈퇴를 요청할 수 있습니다. 필요한 최소한의 본인·권한 확인 후 즉시 삭제·탈퇴 처리를 진행하고 결과를 안내합니다. 탈퇴 처리 시 자체 서버의 대상 계정·학습 기록을 삭제하고, Google 로그인 등에 사용하는 Firebase Authentication의 해당 서비스 인증 계정도 같은 탈퇴 처리 시점에 즉시 삭제 요청·처리합니다. 로그인 차단만 하고 인증 계정을 남겨 두는 방식으로 처리하지 않습니다. 이는 Google 계정 자체를 삭제한다는 뜻은 아닙니다.

여기서 ‘즉시’는 운영자가 탈퇴를 처리하는 시점의 서비스 계정 삭제와 Firebase 계정 삭제 요청을 뜻합니다. Firebase 제공자의 운영·보안 로그나 백업까지 같은 순간에 물리적으로 모두 사라진다고 보장하는 것은 아닙니다. 제공자 관리 영역은 해당 삭제 절차를 따릅니다. 자체 서버 백업도 통상 이용 데이터와 구분해 삭제 절차를 적용하며, 복구 시 삭제된 개인정보가 다시 서비스되지 않도록 관리합니다.

법령상 보존 의무가 있는 정보만 필요한 범위와 법정 기간에 한해 분리 보관하며, 그 사유와 범위를 안내합니다. 보존 의무가 없는 정보를 이를 이유로 무기한 보관하지 않습니다. 전자파일은 복구·재생이 어렵도록 삭제하고 종이 자료는 분쇄 등 안전한 방법으로 파기합니다.
