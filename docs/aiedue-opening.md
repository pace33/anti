# 에이두 한글 별 오프닝

첫 방문에 기존 시작 화면 위에서 16초 오프닝을 재생하고, 마지막에 기존 로고와 노란 시작하기 버튼으로 이어집니다. 버튼의 `showLoginFromStart()` 연결과 로그인·학습 로직을 그대로 사용합니다.

## 장면

- 0–3초: 기존 에이두 캐릭터가 꽃이 있는 들판을 걷습니다.
- 3–6초: 날아온 금빛 별을 따라갑니다.
- 6–11초: 별이 위로 회전하며 올라가고, ㄱ·ㄴ·ㄷ·ㄹ 등 한글 자음 14종이 별에서 퍼져 떨어집니다.
- 11–13초: 별이 하늘에서 부드러운 별빛으로 터집니다.
- 13–16초: 기존 한글 로고와 시작하기 화면으로 전환합니다.

배경, 캐릭터, 로고와 배경음악은 저장소의 기존 자료를 사용합니다. 새 인물이나 로고를 생성하지 않았습니다. Higgsfield AI 영상 생성은 계정 플랜 제한으로 실행되지 않아, Higgsedit의 직접 작성한 모션그래픽으로 제작했습니다.

## 웹 연결

`aiedue-opening.js`와 `aiedue-opening.css`는 `index.html`에서 읽고, 영상은 `assets/opening/aiedue-star-opening.mp4`에 있습니다. 영상은 음소거 자동 재생하며, 사이트 음소거 버튼은 기존 배경음악을 제어합니다. MP4 배경음악은 다운로드하여 별도로 재생할 때 들을 수 있습니다.

브라우저 세션마다 한 번만 자동 재생합니다. 건너뛰기 버튼 또는 Escape로 기존 시작 화면에 즉시 진입할 수 있습니다. 동작 줄이기 설정에서는 오프닝을 생략합니다. 영상 로딩 실패, 자동 재생 거절, 5초 이상의 초기 로딩 지연 시 원래 시작 화면을 유지하고, 25초 이상 재생이 지연되면 오프닝을 종료합니다. 다른 화면으로 이동할 때 재생과 리스너를 정리합니다. 모바일에서는 전체 장면이 보이도록 영상 비율을 유지합니다.

## 검증

`node --check aiedue-opening.js`, `node tools/validate-site.mjs`와 로그인·학습 이동 관련 기존 회귀 테스트를 실행했습니다. 실제 브라우저에서 영상 종료 후 로그인 이동, 세션 내 재생 생략, Escape와 포커스 복원, 동작 줄이기, 영상 실패, 모바일 건너뛰기를 확인했습니다.
