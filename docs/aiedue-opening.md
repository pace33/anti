# 에이두 한글 별 오프닝

첫 방문에 기존 시작 화면 위에서 약 12초 오프닝을 재생하고, 마지막에 기존 로고와 노란 시작하기 버튼으로 이어집니다. 버튼의 `showLoginFromStart()` 연결과 로그인·학습 로직을 그대로 사용합니다.

## 장면

- 0–3초: 후방 카메라가 꽃길을 달리는 에이두의 뒷모습을 따라갑니다. 길 양옆에 언덕·풀숲·꽃·나무가 있습니다.
- 3–6초: 앞쪽으로 날아가는 별에서 ㄱ·ㄴ·ㄷ·ㄹ이 퍼지고, 카메라가 굽은 길을 따라 이동합니다.
- 6–8초: 에이두가 팔을 뻗고 점프하지만 별을 놓칩니다.
- 8–10초: 카메라가 위로 움직이며 하늘로 올라가는 별을 따라가고, 별이 반짝이는 작은 별빛으로 터집니다.
- 9.35–12초: 별빛에서 기존 시작 배경·원본 로고·노란 시작하기 버튼으로 전환하고 약 2초 유지합니다.

달리기·점프·카메라 이동·별빛 장면은 공식 자료를 참고하여 Gemini 웹 앱에서 실제로 생성한 10초 AI 애니메이션입니다. AI가 원본 로고 글자를 정확히 재현하지 못하여, 마지막 화면은 저장소의 원본 배경·로고와 실제 시작 화면의 버튼을 사용해 FFmpeg로 편집했습니다. 이 버전은 Higgsfield를 사용하지 않습니다. 캐릭터와 풍경은 AI가 해석한 표현이며 원본 이미지와 모든 픽셀이 동일하지는 않습니다.

웹용 MP4는 H.264/AAC, 1280×720, 30fps, 약 12초, 약 3.3MB입니다. 생성된 음악과 효과음은 마지막 장면에서 자연스럽게 줄어듭니다.

## 웹 연결

`aiedue-opening.js`와 `aiedue-opening.css`는 `index.html`에서 읽고, 영상은 `assets/opening/aiedue-star-opening.mp4`에 있습니다. 영상은 음소거 자동 재생하며, 사이트 음소거 버튼은 기존 배경음악을 제어합니다. MP4의 음악과 효과음은 다운로드하여 별도로 재생할 때 들을 수 있습니다. 스크립트·영상 캐시와 세션 키는 Gemini 버전으로 갱신했습니다.

브라우저 세션마다 한 번만 자동 재생합니다. 건너뛰기 버튼 또는 Escape로 기존 시작 화면에 즉시 진입할 수 있습니다. 동작 줄이기 설정에서는 오프닝을 생략합니다. 영상 로딩 실패, 자동 재생 거절, 5초 이상의 초기 로딩 지연 시 원래 시작 화면을 유지하고, 25초 이상 재생이 지연되면 오프닝을 종료합니다. 다른 화면으로 이동할 때 재생과 리스너를 정리합니다. 모바일에서는 전체 장면이 보이도록 영상 비율을 유지합니다.

## 검증

초기 연결 구현에서는 로그인·학습 이동 관련 기존 회귀 테스트 30개와 실제 브라우저의 종료 후 로그인 이동, 세션 내 재생 생략, Escape와 포커스 복원, 동작 줄이기, 영상 실패, 모바일 건너뛰기를 확인했습니다. 이번 영상 교체에서는 JavaScript 문법 검사와 사이트 구조 검증, MP4 전체 디코딩, 주요 장면과 원본 로고 엔딩을 확인했습니다. 현재 Chrome의 동작 줄이기 설정에 따른 오프닝 생략, MP4 재생, 기존 시작하기 버튼에서 학생 로그인 화면으로의 이동도 확인했습니다.
