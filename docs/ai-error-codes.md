# AI 오류 안내와 4단계 생성 복구

## 화면 표시 원칙

AI 요청 실패 시 제공자명, 모델명, CLI 이름, 내부 오류·stderr·stdout을 사용자 화면에 출력하지 않습니다. 안내는 다음 형식만 사용합니다.

> AI 생성에 실패했습니다. 오류 코드: AI-1001

`ai-error-utils.mjs`의 `aiErrorMessage`/`createAiError`를 재사용합니다. 4단계 문제 생성·서술형 채점, 3단계 사진 분석·쓰기/받아쓰기 채점, 뜻·그림 카드, AI 스케치북, 이미지 조정, 동화책 삽화 오류에 적용됩니다. 사용자가 직접 취소한 요청은 실패로 바꾸지 않습니다.

## 코드

- AI-1001: AI 서비스 일시 장애
- AI-1002: 처리 시간 초과
- AI-1003: 요청·사용량 제한
- AI-1004: 접속 인증·권한 실패
- AI-1005: 잘못된 요청
- AI-1006: 생성 결과 형식 오류
- AI-1007: 허용되지 않은 도구 실행
- AI-1008: 네트워크 연결 실패
- AI-1009: 만료되거나 없는 작업/세션
- AI-1099: 기타 생성 실패

서버 코드가 있으면 그대로 보존하고, 구형 응답이나 오류 객체는 같은 코드 체계로 정규화합니다. 임의의 코드/메시지는 그대로 화면에 표시하지 않습니다.

## 4단계 생성 복구

운영 로그에서 생성 시작 전 서비스 사용 가능 확인이 HTTP 503으로 실패하는 사례를 확인했습니다. 서버는 **아직 생성 요청이 전송되지 않은 이 시작 실패만** 최대 두 번 추가 재시도합니다(1초, 2초 대기). 요청이 이미 전송됐거나, 시간 초과·사용량 제한·인증 실패·일반 오류라면 자동 반복하지 않습니다. 새 문제를 임의로 만들어 성공한 것처럼 대체하지 않습니다. 마지막 실패도 동일한 오류코드 안내를 사용합니다.

원인 분석용 상세 로그는 서버에 남기고 공개 오류 응답에는 고정 문구와 코드만 반환합니다. 사진 기반 분석은 재시도하는 동안 원본을 보존하고 모든 시도가 끝난 뒤 삭제합니다.

## 검증

```sh
node --test tools/test-ai-error-codes.mjs tools/test-image-job-errors.mjs tools/test-curricular-photo-transition.mjs
```

실제 검증은 로그인 → 4단계 생성 → 정답 선택/입력 → 피드백 → 자체 데이터 서버의 문해력 기록 저장까지 확인합니다. 제공자 정보 노출 회귀는 별도의 의도적인 실패 응답을 주입해 검증하며, 실제 생성 성공과 구분해 보고합니다.
