요청하신 이의제기 사항과 관련하여, 에이두 한글의 AI 기능 구현 방식과 자체 서버 운영 구조, 학급 내 교육적 활용을 다음과 같이 소명드립니다.

자체 AntiAI API를 통한 AI 기능 구현

에이두 한글은 개발자가 구축한 자체 AntiAI 서버의 API를 통해 AI 기능을 제공합니다. AntiAI는 이용자의 요청을 받아 개인정보와 위험·유해정보에 대한 필터링을 적용하고, 작업의 종류와 처리 상황에 따라 연결된 AI 모델로 요청을 전달한 뒤 결과를 받아 제공하는 서버입니다.

AntiAI에는 이미지 생성·편집을 위한 로컬 모델인 Qwen Image 2.1, 문장 생성·분석을 위한 로컬 언어 모델인 Gemma4, Antigravity CLI를 통한 AI 처리 경로가 함께 연결되어 있습니다. 이미지 작업과 언어 작업 모두 로컬 모델과 Antigravity CLI 경로를 사용할 수 있도록 구성되어 있습니다.

따라서 에이두 한글에서 직접 호출하는 인터페이스는 자체 AntiAI API입니다. Gemini API를 연동하여 요청을 처리하지 않습니다.

로컬 모델 우선 처리와 Antigravity CLI 자동 전환

AI 요청은 기본적으로 로컬 모델에서 먼저 처리하도록 설정되어 있습니다. 다만 로컬 처리에 시간이 오래 걸리거나 여러 이용자의 요청이 동시에 들어와 설정된 시간 안에 응답이 완료되지 않으면, Antigravity CLI 경로로 자동 전환하는 방식으로 운영하고 있습니다. 이는 수업 중 응답 지연으로 학습 활동이 중단되는 상황을 줄이기 위한 처리 방식입니다.

기존 설명에서 Gemini 3.6 Flash를 기재한 것은 이처럼 실제 이용 과정에서 주로 제공되는 응답의 모델을 설명하기 위한 것이었습니다. 현재 운영 상태를 로컬 AI만으로 구동되는 것처럼 안내하는 것은 정확하지 않다고 판단하여 해당 모델로 명시했습니다.

그리고 Gemini를 사용하는 것 또한 API를 사용하는 것이 아닌, AntiAI 로컬 서버에서 Antigravity CLI의 입출력을 필터링하여 제공하는 방식이므로, Gemini API 지적에 해당되지 않습니다.

개발자 개인 서버의 운영과 학급 내 교육적 활용

에이두 한글은 개발자인 교사가 자신의 학급에서 학생들과 함께 활용하기 위해 직접 개발·운영하는 교육용 프로젝트입니다. 수업에 필요한 기능과 자료를 개발자가 직접 구성하고 관리하며, 학급의 학습 활동을 지원하는 목적으로 사용하고 있습니다.

서비스의 CI·배포와 운영 자동화는 개발자가 관리하는 개인 서버 환경에서 이루어집니다. 웹서비스는 자체 Caddy 서버를 통해 제공하며, 서비스 계정과 학습 기록은 자체 SQLite 데이터베이스 및 관련 저장소에서 관리합니다.

AI 기능 역시 자체 AntiAI 서버를 중심으로 연결되어 있습니다. 로컬 모델과 Antigravity CLI 중 어느 경로를 사용하더라도 에이두 한글의 요청과 응답은 AntiAI를 거치며, 이 과정에서 개인정보와 위험·유해정보에 대한 필터링을 적용합니다. 외부 처리 경로로 전환하는 경우에는 필터링을 거친 작업 입력을 전달하고, 생성된 응답을 다시 받아 서비스에 제공합니다.

Antigravity CLI 경로는 개발자 개인의 유료 구독 계정으로 로그인된 CLI의 비대화형 세션을 자체 서버에서 실행하는 방식입니다. 학생은 에이두 한글의 학습 화면을 이용하며, 개발자의 Antigravity 계정에 직접 로그인하는 방식으로 사용하지 않습니다.

이와 같이 에이두 한글은 개발자가 자신의 서버와 학급 환경을 바탕으로 직접 운영하는 프로젝트이며, AntiAI가 로컬 모델과 외부 처리 경로의 연결 및 입출력을 관리하는 구조입니다.

이의제기 사항에 대한 의견

에이두 한글의 AI 기능은 자체 AntiAI API를 중심으로 여러 모델을 연결하고, 로컬 모델을 우선 사용하되 처리 상황에 따라 Antigravity CLI로 전환하는 방식으로 구현되어 있습니다.

따라서 에이두 한글을 Gemini API에 직접 연결하여 운영하는 서비스로 보거나, Gemini 모델명에 대한 설명만으로 전체 구현 방식을 판단하는 것은 실제 구조와 다릅니다. 기존 설명에 Gemini 모델을 명시한 것은 응답의 처리 기반을 안내하기 위한 것이었습니다.

위와 같이 자체 AntiAI 서버를 통한 입출력 관리와 필터링, 복수 모델의 연결 및 자동 전환 구조, 개발자 개인의 학급 내 교육적 활용과 함께 에이두 한글의 운영 목적과 기술적 구조를 안내드립니다.
