# 교과 맞춤쓰기 중간 저장

3단계 교과 맞춤쓰기의 2스텝 따라쓰기 또는 3스텝 받아쓰기를 완료하지 않고 나가도 **교과 맞춤 다시 쓰기 → 중간 저장 → 이어서 쓰기**로 다시 열 수 있습니다. `나의 교과 맞춤쓰기` 학습 기록 탭에도 같은 목록이 있습니다.

- 로그인 계정의 자체 데이터 서버 `users/{uid}.dictationPortfolio.curricularWriting.drafts`에 최근 5개 학습을 저장합니다. Firebase는 로그인 인증에만 사용합니다.
- 쓰기 화면 진입, 획 입력 후 잠깐의 유휴 시간, 확인/지우기/이전/다음, 다른 화면 이동, 탭 숨김 때 저장을 요청합니다. **중간 기록 저장됨** 표시로 서버 저장을 확인하세요.
- 단어와 문장, 진행 위치, 손글씨 획, 확인 결과 및 재도전 상태를 복원합니다. 획은 프로필 크기 제한을 위해 정규화·샘플링하며 원본 사진은 중간 기록에 넣지 않습니다.
- 같은 학습의 따라쓰기→받아쓰기 전환은 하나의 중간 기록을 갱신합니다. 정상 완료 후에는 중간 목록에서 제거되고 기존 완료 기록 처리로 넘어갑니다.
- 중간 기록 자체는 완료 횟수·정답률·오답 은행·보상에 반영하지 않습니다. 실제 확인 버튼으로 채점한 음절 기록은 기존 규칙을 유지합니다.
- 네트워크 연결이 없거나 저장 응답 전에 브라우저/기기가 강제 종료되면 마지막 변경을 보장할 수 없습니다. 저장 실패 시 오류 안내를 표시하며 이후 획 입력/확인/화면 이동으로 재시도합니다. 로컬 브라우저 저장소에는 별도 복사본을 만들지 않습니다.

## 검증

`node --test tools/test-curricular-writing-drafts.mjs`

실제 계정으로 사진 분석→쓰기에 획 입력→중간 저장 응답→나가기→다시쓰기 목록→다른 브라우저 로그인→이어서 쓰기의 흐름과 자체 서버 읽기 결과를 함께 확인합니다. 중간 저장이 지갑/완료 횟수/통계에 영향을 주지 않는지, 완료 시 중간 기록 제거와 완료 기록 보존도 확인합니다.
