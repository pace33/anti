# 학생 현황: 변경량과 변경 후 수치

학급 관리 → 학생 현황에서 경험치, 돈, 주의토큰 기록에 변경량과 변경 후 수치를 함께 표시한다.

- 경험치: `경험치 +5.0% → Lv.1 25.0% (Lv.1 20.0%에서)`
- 돈: `돈 +1,000점 → 3,000점 (2,000점에서)`
- 주의토큰: `주의토큰 -1개 → 2개 (3개에서)`

## 기록 계약

`koreanActivityLog`의 각 이벤트에 `statusSnapshotVersion: 1`과 수치 쌍을 저장한다.

- `experienceBefore`, `experienceAfter`, `levelBefore`, `levelAfter`
- `balanceBefore`, `balanceAfter`
- `warningTokensBefore`, `warningTokensAfter`

트랜잭션 보상 경로는 서버 프로필을 읽은 값과 같은 트랜잭션에서 저장하는 결과를 사용한다. 일반 활동의 기존 로컬 보상 경로는 보상을 적용하기 직전과 직후를 사용한다. 교사의 과다 차감은 요청량이 아니라 0 하한 적용 후 실제 변경량을 표시한다. 레벨이 오를 때 경험치 변경량은 레벨 차이×100 + 경험치 차이로 계산하여 감소로 잘못 표시하지 않는다.

그리기 보상, 일반 활동 보상, 시간 퀴즈, 문해력 활동·오답 복습, 교사 돈·주의토큰 지급/차감에 적용한다. 그리기·문해력에서 경험치 없이 돈만 받는 경우도 기록한다.

원래 활동·배율 설명은 유지하고 다음 줄에 `변화:`를 표시한다. 기록에 당시 수치가 없는 예전 활동은 오늘의 현재값으로 소급 계산하지 않고 기존 문구를 유지한다. 이 기능은 다른 앱/상점/송금 등 기존에 학생 현황 기록을 생성하지 않는 경로에 새 기록을 만드는 기능이 아니다.

## 검증

- `node --test tools/test-student-activity-status.mjs tools/test-student-activity-log-labels.mjs`
- `node --input-type=module --check < app.js`
- `node tools/validate-site.mjs`
- 학생 테스트 계정의 실제 경험치 저장 → 영수증 중복 보상 방지 → 교사 학생 현황 렌더링
- 교사 테스트 계정의 실제 돈·주의토큰 지급/차감 버튼 → 자체 데이터 서버 저장 → 변경 전/후 대조
- PC/390px 모바일 가로 넘침, 콘솔 오류 확인

테스트 계정만 변경하며 원래 지갑 수치를 동시 변경 감지 후 복원한다. 임시 시간 퀴즈 영수증·활동은 정리하고 교사 지급/차감 감사 이력은 유지한다.
