# 발표 원고 읽기

공개 주소: https://aiedue.ddns.net/korean/reader/

- 왼쪽 원고를 클릭해 입력하거나 일반 텍스트를 붙여 넣습니다.
- 원고 오른쪽 `↕` 손잡이를 위아래로 끌면 주황색 선 바로 아래 줄이 읽기 시작점이 됩니다. 화면 끝으로 끌면 원고가 스크롤됩니다.
- 손잡이에 키보드 초점을 두고 위/아래 방향키로 한 줄씩, Home/End로 처음/마지막 줄로 이동할 수도 있습니다.
- 재생하면 책갈피부터 원고 끝까지 읽습니다. 읽는 줄은 연한 색, 발음 중인 어절은 진한 색으로 표시되며 화면이 따라 내려갑니다.
- 일시정지 후에는 현재 어절부터 이어 읽습니다. 읽기 초기화는 원고를 지우지 않고 책갈피만 맨 처음으로 옮깁니다.
- 읽는 동안 원고 편집은 잠깐 잠깁니다. 일시정지하면 수정할 수 있습니다.
- 목소리, 속도, 글자 크기를 오른쪽에서 조절합니다. 스톱워치는 음성 재생과 독립적으로 시작/일시정지/초기화합니다.
- 원고, 책갈피, 읽기 설정은 현재 기기의 브라우저에 자동 저장됩니다. 계정 간/기기 간 동기화는 없습니다. 브라우저 데이터 삭제 시 사라지므로 중요한 원고는 별도로 보관하세요.

## 음성 및 지원 환경

브라우저 Web Speech API를 사용하므로 별도 AI 키나 서버의 TTS 프로세스가 필요 없습니다. 목소리의 종류와 품질은 기기/브라우저에 따라 다릅니다. Windows Chrome/Edge의 한국어 목소리를 권장합니다. 실제 발화의 `word` boundary 이벤트로 어절을 강조합니다. boundary 이벤트를 보내지 않는 음성은 첫 다어절 문장 이후 어절 단위 발화로 자동 전환하므로 다소 끊어 들릴 수 있습니다. 음성은 브라우저/운영체제가 처리하며, 해당 목소리의 로컬/온라인 동작은 제공 환경에 따릅니다.

첫 방문에는 제공받은 에이두 한글 발표문이 채워집니다. 편집 후에는 이 기기에 저장한 원고가 우선입니다.

## 검증

`node --test tools/test-presentation-reader.mjs`

브라우저 검증은 별도의 임시 Playwright 환경에서 수행합니다. 중간 시각 줄 드래그 → 해당 어절부터 재생, word boundary에 맞춘 줄/어절 강조, 전체 긴 원고의 순서/누락/중복, 일시정지/재개, 초기화, 문단/빈 줄 저장 후 새로고침, 스톱워치, 360~1360px 오른쪽 사이드바, HTML 문자열 안전 표시를 확인합니다. 실제 OS 음성의 발화 이벤트/강조 검증은 합성 이벤트 UI 테스트와 구분합니다.
