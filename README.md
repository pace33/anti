# 에이두 한글

특수교육 수업에서 사용하는 한글 해득·받아쓰기·문해력·그리기 중심 웹앱입니다.

- 운영 주소: <https://aiedue.ddns.net/korean/>
- 실행 파일: `index.html`
- 기능 로직: `app.js`
- 스타일: `style.css`, `app.css`
- 데이터: Firebase Auth, Firestore
- 상세 구조: [에이두 국어 구조도](./에이두%20국어%20시리즈%20구조도.md)

운영 배포는 `main` 브랜치 병합 후 자체 실행기에서 자동 진행됩니다.
개인정보나 수업 준비용 임시 자료는 이 저장소에 올리지 않습니다.

## 에이두 수학

완성형 수학 앱은 [`math/`](./math/)에 있습니다. `aiedue-math-backup/`은 복원 당시의
원본을 보존하며, 실제 기능 개발과 검증은 `math/`에서 진행합니다. 수학 앱은 Firebase
Auth로 로그인하고 에이두 데이터 서버에 진도·시도·교사 배정·상점 기록을 저장합니다.
