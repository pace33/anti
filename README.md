# 에이두 한글

특수교육 수업에서 사용하는 한글 해득·받아쓰기·문해력·그리기 중심 웹앱입니다.

- 운영 주소: <https://aiedue.ddns.net/korean/>
- 실행 파일: `index.html`
- 기능 로직: `app.js`
- 스타일: `style.css`, `app.css`
- 데이터: Firebase Auth, Firestore
- 상세 구조: [에이두 국어 구조도](./에이두%20국어%20시리즈%20구조도.md)

운영 배포는 `main` 브랜치 병합 후 자체 실행기에서 자동 진행됩니다.
개인정보나 수업 준비용 임시 자료는 이 저장소에 올리지 않습니다.

## 에이두 연구실 · 도형 동물원

홈의 **에이두 연구실 → 도형 동물원**에서 실행합니다. `shape-zoo.html`에서도 바로 체험할 수 있습니다.
사자의 말풍선 속 도형을 점선에 따라 그린 뒤 완료하면, 그린 그림이 있는 과자를 전달합니다.
성공하면 게임 점수 +1, 실패하거나 시간이 지나면 생명 -1이며 생명 3개를 모두 쓰면 종료됩니다.
제한 시간은 18초부터 성공할 때마다 0.6초씩 줄어들고 최소 6초를 유지합니다.

`drawing-shape-catalog.mjs`의 목록을 **1단계 나의 도형**과 함께 사용합니다.
직선·꾸불선·동그라미·세모·네모·별·오각형·하트·마름모·지그재그 10종이 모두 한 번씩 나온 뒤 다시 섞입니다.
그림은 여러 획으로 나누어 그릴 수 있고, 다시 그리기는 제한 시간을 초기화하지 않습니다.
다른 탭으로 이동하면 일시정지하며 이어서 하기를 눌러 재개합니다. 게임 점수는 해당 플레이 중에만 유지됩니다.

검증: `node --test tools/test-shape-zoo-core.mjs tools/test-shape-zoo-game.mjs`

## 에이두 연구실 · 단어 카드 한 판 (3단계)

로그인 후 **에이두 연구실 → 단어 카드 한 판**에서 실행합니다. 친구가 이름을 가린 카드를 책상에 놓으면
그림과 설명을 보고 내 카드 네 장 중 하나를 냅니다. 모든 카드는 **그림 → 단어 → 설명** 순서입니다.
정답은 박수와 함께 +1점, 오답은 친구의 ‘아이고’ 반응과 정답 확인으로 이어집니다.
다음 카드 받기를 누르면 새 문제를 받으며, 시간 제한이나 생명 차감은 없습니다.
점수는 해당 게임 중에만 유지되고 게임 마치기에서 결과를 확인합니다.

매 문제마다 기존 `sharedWordCardsV1` 저장소를 조회합니다. 공개·발행 완료·버전 1 카드 중
유효한 저장소 그림 경로와 단어·설명이 있는 카드만 사용합니다(조회 상한 500장).
같은 단어를 중복 보기로 쓰지 않으며 직전 정답은 연속으로 내지 않습니다.
카드가 네 종류 미만이거나 저장소/그림 로딩에 실패하면 안내와 재시도를 제공합니다.
별도 예시 카드, 자동 카드 생성, 대체 그림은 넣지 않습니다. 실제 카드 로딩에는 에이두 로그인과 데이터 서버 연결이 필요합니다.
탭을 숨기거나 Escape를 누르면 일시정지하며, 나가기·계정 변경 시 진행 중 요청과 화면을 정리합니다.

검증: `node --test tools/test-word-card-table-core.mjs tools/test-word-card-table-game.mjs tools/test-word-card-table-source.mjs`

## 에이두 수학

완성형 수학 앱은 [`math/`](./math/)에 있습니다. `aiedue-math-backup/`은 복원 당시의
원본을 보존하며, 실제 기능 개발과 검증은 `math/`에서 진행합니다. 수학 앱은 Firebase
Auth로 로그인하고 에이두 데이터 서버에 진도·시도·교사 배정·상점 기록을 저장합니다.
