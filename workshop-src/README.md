# 에이두 수업 공방

사용자가 제공한 한울반 교실 프로젝트의 학습지·미션·기록·교실 운영 기능을 에이두 한글 연구실용으로 이식한 소스입니다. 원본 Next/Vinext 서버, D1 DB, 배포 설정, 저장된 개인 기록은 포함하지 않습니다.

## 빌드

Node.js 22.13 이상에서 이 디렉터리의 `npm ci` 후 `npm run build`를 실행합니다. `../workshop/`에 생성된 정적 파일도 함께 커밋합니다. 경로는 상대 경로이므로 `/korean/` 하위 배포를 지원합니다.

## 연결

- 교사 계정 → 에이두 연구실 → 에이두 수업 공방에서 실행합니다.
- 부모 페이지의 `workshop-launcher.mjs`가 프레임별 세션을 제공합니다. 단독으로 열면 진입 안내를 표시합니다.
- `workshop-service.mjs`는 기존 한글 데이터 어댑터를 사용합니다. 교사의 학급 학생을 읽고, `users/{teacherId}/workshopEntries/{entryId}`에 공방 기록을 저장합니다. 학생 계정 생성이나 학급 명단 변경은 기존 학급 관리에서 수행합니다.
- 모든 작업에서 교사 신원을 검사하고, 닫기·계정 변경 시 세션을 폐기합니다. 삭제는 `deletedAt`을 기록해 목록에서 제외합니다.
- 교실 쿠폰 장부는 별도의 활동 기록입니다. 에이두 포인트·경험치·주의토큰은 변경하지 않습니다.
- 학습지와 쿠폰은 프레임 내부의 인쇄 스타일로 출력합니다. 읽기 자료 사진은 제공받은 자료의 정적 자산이며, 쿠폰 양식은 HTML로 다시 구성했습니다.

서비스 회귀 테스트: 저장소 루트에서 `node --test tools/test-workshop-service.mjs`.
