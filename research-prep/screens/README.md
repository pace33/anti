# 발표용 실화면

이 폴더의 발표 사용 이미지는 `https://aiedue.ddns.net/korean/`의 **학생 테스트 계정과 기본 사용법 체험**에서 직접 캡처했습니다.

- 현재 기능과 학생 조작 흐름을 보여 주는 시연 자료입니다. 연구 당시 학생의 활동 결과·수업 사진·효과 증거가 아닙니다.
- 캡처에 보이는 ‘학생 테스트’는 실명 학생이 아닙니다. 실제 학생 계정·원본 보고서·학생 원자료를 촬영하거나 공개하지 않았습니다.
- 그리기의 예시 그림, 따라쓰기의 ‘나무’, 문해력의 화분 지문은 앱의 기본 체험 예시입니다.
- 외부 조작 안내 말풍선은 체험 스크립트의 안내 레이어만 숨겼습니다. 실제 앱의 학습 UI·정보바·학습 내용을 가짜 그림으로 대체하지 않았습니다.
- 사진 가져오기는 카메라·사진을 선택하는 실제 안내 화면입니다. 실제 교과자료를 업로드한 결과 화면으로 제시하지 않습니다.
- 발표에서 사용하는 이미지 목록과 배치 장수는 `../presentation.json`에 있습니다. 연구 수업 사례와 수치의 근거는 `../../docs/research-submitted-report-basis.md`입니다.
